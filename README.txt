DAT CONSTRUCTION WEBSITE
========================

Files:
- index.html  : complete responsive website
- style.css   : visual design and responsive layout
- script.js   : contact details, navigation and enquiry mailto form

IMPORTANT BEFORE DEPLOYMENT
---------------------------
1. Open script.js.
2. Replace:
   phoneDisplay
   phoneDial
   email
   with DAT Construction's VERIFIED phone number and email.
3. Replace or add official logo, project photographs, certifications,
   GST/Udyam details and verified project completion documents.
4. The project values and tender statistics in index.html are based on
   publicly available tender-profile information supplied for this build.
   Verify them against official tender/award records before using them
   as formal credentials.
5. For production lead capture, replace the mailto form with a secure
   backend/form service or company CRM.

DEPLOYMENT
----------
This is a static website and can be hosted on Netlify, Vercel, GitHub Pages,
Cloudflare Pages or any normal web server.
